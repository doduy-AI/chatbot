1. GITHUB
--------------------------------------------------------------------------------
• Read repo tối thiểu; Deploy key cần quyền Admin/Maintain.
• Pull: không dùng mật khẩu GitHub.
  A) SSH (nên dùng): ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_github -N ""
     → add .pub vào Repo → Deploy keys → ~/.ssh/config:
       Host github.com / HostName github.com / User git
       IdentityFile ~/.ssh/id_ed25519_github / IdentitiesOnly yes
     → git remote set-url origin git@github.com:bytehomerepo/chatbot_voice.git
  B) HTTPS: PAT làm “password”.
• .pem SSH máy cloud: không commit.

6. SERVER HTTP (cổng 8000)
--------------------------------------------------------------------------------
tmux new -s tts
cd .../AI_Service/tts_service && python3 server.py
Thoát giữ process: Ctrl+B, D  |  Vào lại: tmux attach -t tts  |  Tắt: Ctrl+C
GET health: curl -sS http://127.0.0.1:8000/health
POST JSON {"text":"..."} → file WAV. Tránh tmux lồng tmux.

--------------------------------------------------------------------------------
7. WINDOWS (tunnel + gọi API)
--------------------------------------------------------------------------------
ssh -i .\mykey.pem -P <port> root@<IP> -L 8000:localhost:8000
Chỉ test sau khi server in "Server đang chạy...:8000".
PowerShell — tránh curl -d "{\"...  (lỗi parse). Dùng:
  $b = @{ text = "Xin chào" } | ConvertTo-Json -Compress
  Invoke-WebRequest -Uri http://127.0.0.1:8000/ -Method POST -Body $b `
    -ContentType "application/json; charset=utf-8" -OutFile ~\Desktop\tts.wav
Hoặc: curl.exe ... --data-raw '{"text":"Xin chao"}' -o ...
File ~1KB + chữ {"error" → JSON lỗi, không phải WAV.

--------------------------------------------------------------------------------
8. XUẤT 18 FILE WAV
--------------------------------------------------------------------------------
Tắt server.py trước (tránh 2 lần load model / OOM).
cd .../AI_Service/tts_service
python3 export_cau_test_wav.py --out ../../tts_test_output/sau_fix_$(date +%Y%m%d)
Đếm: ls -1 .../sau_fix_YYYYMMDD/*.wav | wc -l  → 18. Xong bật lại server nếu cần.

9. SCP VỀ WINDOWS
--------------------------------------------------------------------------------
scp -i .\mykey.pem -P <port> -r root@<IP>:/path/tts_test_output/sau_fix_YYYYMMDD "%USERPROFILE%\Desktop\"

--------------------------------------------------------------------------------
10. LỖI THƯỜNG GẶP
--------------------------------------------------------------------------------
HTTPS auth fail     → PAT hoặc SSH deploy key
publickey denied    → key + ~/.ssh/config + Deploy keys
refused :8000       → server chưa chạy / chưa load xong
SSH channel refused → forward nhầm cổng trống (chỉ -L 8000 nếu chỉ TTS)
nutrem thiếu        → bản mới bỏ qua nutreem; chỉ cần giongnuhanoi6s.wav
torio/FFmpeg crash  → apt install ffmpeg; WAV ref đọc qua soundfile/wave trong code
Empty reply / JSON  → mục 7
OOM                 → không chạy server + export cùng lúc

11. NGHIỆM THỬ & BÀN GIAO
--------------------------------------------------------------------------------
Mục tiêu: đọc dài trơn; nối chunk không khựng; không còn lỗi kiểu "..." mỗi chunk / ghép PCM thô (đã có pipeline chunk+crossfade).

Dry-run: export ... --dry-run → dry_run_chunk_report.txt

Ghi nhận: từng 00x — OK / cắt / hụt / click nối.
Giao hàng: code (tts_pipeline, tts_service, server, tts_paths, .env.example) + script + 18 wav + báo cáo 1 trang.
Ngoài phạm vi: G2P song ngữ sâu; train lại XTTS.

--------------------------------------------------------------------------------

Đổi model → chạy lại 18 câu so A/B.
