Dùng checkpoint capleaf/viXTTS (Hugging Face)
============================================

Model: https://huggingface.co/capleaf/viXTTS

File cần: model.pth, config.json, vocab.json (cùng bộ trong repo HF).

Cách 1 — huggingface-cli (khuyến nghị)
--------------------------------------
  pip install -U huggingface_hub
  cd AI_Service/tts_service
  mkdir model_vixtts
  huggingface-cli download capleaf/viXTTS config.json model.pth vocab.json --local-dir model_vixtts

Giữ nguyên file giọng ref (wav) trong thư mục đó hoặc trỏ VOICE_PROFILES tới đường dẫn wav có sẵn.

Cách 2 — tải tay trên web Files tab của HF, copy 3 file vào model_vixtts/

Chạy service với viXTTS
-----------------------
  set TTS_MODEL_DIR=model_vixtts
  set TTS_MIN_WORDS_PER_CHUNK=10
  python wordker.py
  (Linux/mac: export TTS_MODEL_DIR=...)

TTS_MIN_WORDS_PER_CHUNK=10 — viXTTS kém với câu tiếng Việt dưới ~10 từ (theo model card HF);
pipeline sẽ gộp các chunk ngắn lại trước khi inference.
